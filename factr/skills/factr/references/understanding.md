# Interpret source meaning

## Resolve semantic roles

A document title, feature label, release label, or organizational container is different from the entity performing the operative behavior.

Explain lifecycle connections, handoffs, exception reach and responsibility boundaries. Repeated vocabulary alone does not establish those relationships.

## Compare the readings that matter

Compare how candidate readings change responsibility, scope or lifecycle completion. Include operating perspective when the wording could describe real operation, simulation, demonstration or a hypothetical example; an unusual phrase alone does not select that perspective.

"Does retention include a process restart?" asks about policy. Lifecycle notes can define that policy, while persistence code or a before/after restart comparison can describe implementation behavior. Identify which kind of question each investigation could answer.
